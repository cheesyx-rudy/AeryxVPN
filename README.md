# 🟡 LIKVID VPN

**LIKVID VPN — свобода не предмет роскоши, она должна быть доступна всем.**

Бесплатная агрегированная подписка с прокси-конфигурациями из открытых источников. Поддерживаются VLESS, VMess, Trojan, Hysteria2 и другие протоколы.

## ⭐ Что выбрать?

Если не знаете, с чего начать, попробуйте Hiddify. В остальных случаях выбирайте клиент, который поддерживает протоколы используемых конфигураций.

## ⏱ Маршрутизация Happ

В основную подписку интегрирован профиль маршрутизации для клиента Happ. Его использование необязательно — при необходимости профиль можно отключить в настройках клиента.

Корректная работа маршрутизации не гарантируется на всех устройствах и конфигурациях. После обновления подписки проверьте настройки и работу нужных сервисов.

## 🎯 Как работают подписки

Конфигурации автоматически собираются и обновляются из открытых источников. В подписках могут встречаться прокси из разных стран и на разных протоколах.

- Мы не являемся владельцами всех размещённых конфигураций и не гарантируем работоспособность каждого узла.
- Конфигурации могут перестать работать без предупреждения.
- Разные клиенты могут поддерживать разные протоколы и параметры.
- Если конфигурация не подключается, попробуйте другой узел или совместимый клиент.
- Отдельная подписка для Clash-клиентов больше не поддерживается.
